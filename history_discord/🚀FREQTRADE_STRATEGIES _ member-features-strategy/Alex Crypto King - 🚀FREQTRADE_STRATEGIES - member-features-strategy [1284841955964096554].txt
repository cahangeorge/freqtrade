This is the @Ch1cK3N_t4c0s futures strategy but with some addition!!!!

1_Disabled short entries for now, I know they are in developping (it makes huge DD anche for testing I'd shut it down, anyway, also with Long only it's a killer strategy)

2_SPREEEEAD! I added my custom code environment based on BTC spread fetched in realtime! This code can scan spread oscillations and decide how to manage the strategy based on this info. 
ex: When we have a big forex news, also BTC go crazy, and his spread make 30/50x... this is very dangerous for EVERY strategy, because in this particular moment big candle happen. 
So, this spread environment try to read spread anomalies and exit position that are in losses and keep the other that are in profit... all this  in some second. 
Next, this spread env have another function. It makes a BUY PAUSE... why? when spread go crazy after a big news, a BIG candle happen, but it's not finish... infact many many strategy read this big candle as a spike o a valley, and place trades just after this candle... but many time, the crazyness it's not finish, also if the spread is under the limits.... the market continue for some minute to be very volatile... this pause (1 hour, but you can change it) avoid entries on false spikes/valleys. 

PS: This is not backtestable, bid and ask are fetched in realtime from orderbook, so, no history.

PS2: We fetch only the BTC spread, and it is pasted on all pairs dataframes.  This because: 1 if we fetch all pairs spread the strategy will be very slow. 2 BTC is the fathers of all crypto, if his spread go crazy, all the market go crazy. 3 Every pair have different spread value, so it's better to have just 1 spread to manage all the strategy

so there is no need to set it like this:

    # trailing_stop trailing
    #trailing_stop = BooleanParameter(default=False, space="trailing", optimize=True, load=True)
    #trailing_stop_positive = DecimalParameter(low=0.0, high=1.0, default=0.5, decimals=1 ,space='trailing', optimize=True, load=True)
    #trailing_stop_positive_offset = DecimalParameter(low=0.0, high=1.0, default=0.5, decimals=1 ,space='trailing', optimize=True, load=True)
    #trailing_only_offset_is_reached = BooleanParameter(default=False, space="trailing", optimize=True, load=True)

simply just add:

    # trailing_stop trailing
    trailing_stop = True
    trailing_stop_positive = 0.05
    trailing_stop_positive_offset = 0.01
    trailing_only_offset_is_reached = True

hyperopt will do the rest, i tested it without the custom stoploss end it is triggered.
