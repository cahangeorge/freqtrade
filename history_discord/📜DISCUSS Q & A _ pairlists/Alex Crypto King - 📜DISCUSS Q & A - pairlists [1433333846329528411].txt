@everyone 
🚀 ML / Backtest Pairlist Optimizer (Freqtrade)

I built a standalone pairlist optimizer that automatically finds the best tradable pairs for any Freqtrade strategy — ML or non-ML.

🔍 What it does

Generates a dynamic pairlist from your exchange filters
Runs per-pair backtests (one coin at a time)
Supports ML strategies (uses train/val accuracy)
Supports non-ML strategies (uses profit, win rate & drawdown)
Ranks pairs and exports a ready-to-use pairlist
Has TEST MODE (exploration) and PROD MODE (strict filtering)
Perfect for:
finding better markets
avoiding bad coins
validating strategies before live trading

⚙️ How it works (simple)
ML strategies → ranked by validation accuracy & generalization
Non-ML strategies → ranked by win rate, profit & drawdown
Test mode → shows results even if they’re bad (research)
Normal mode → only returns pairs that pass quality rules
Optuna - it disables Optuna optimizing for Backtest

🧪 Usage
python user_data/pairlist/Alex_Pairlist_Selector.py \
  --config user_data/pairlist/config-pairlist.json \
  --strategy YourStrategyName \
  --pairs-file user_data/pairlist/dynamic_pairs.json \
  --n-pairs 50

🧰 Arguments

--config → Freqtrade config (with pairlist filters)
--strategy → Strategy name (ML or non-ML)
--pairs-file → Input/output dynamic pairlist JSON
--n-pairs → Number of top pairs to return
--no-download → Skip candle downloads
--download-days → History length (default: 60)
--test-mode → Research mode (no filtering, no crashes)

✅ Output

optimal_pairs.json → final ranked pairlist

Clean logs showing why pairs passed or failed

Safe handling of ML / non-ML / single-pair backtests

If anyone wants to build smarter pairlists instead of guessing, this tool does the heavy lifting 🤖📊
