def perform_fft(price_data, window_size=None):
    if window_size is not None:
        # Apply rolling window to smooth the data
        price_data = price_data.rolling(window=window_size, center=True).mean().dropna()

    normalized_data = (price_data - np.mean(price_data)) / np.std(price_data)
    n = len(normalized_data)
    fft_data = np.fft.fft(normalized_data)
    freq = np.fft.fftfreq(n)
    power = np.abs(fft_data) ** 2
    power[np.isinf(power)] = 0
    return freq, power

(!) I'm working on a BTC protection code however im having some issues and need some help fixing it. If someone is interested to take a look I would appreciate it:

Currently it exits all positions, long or short and still allows bidirectional trading when it should be restricted as per below:

This ideea behind it is this:

If BTC drops in 1 candle a certain % in a candle or multiple candles, it will emergency exit long positions, will leave short positions open and will not allow longs for a number of minutes.

similar for Pump: If btc pumps more than a certain % in a candle or multiple candles, it will emergency exit short positions, it will leave long positions open and will not allow shorts for a number of minutes.


def custom_exit(self, pair: str, trade: 'Trade', current_time: 'datetime', current_rate: float, current_profit: float, **kwargs):
        btc_pct_change = self.get_btc_price_change()

        if btc_pct_change <= -0.4:
            logger.info(f'BTC dropped more than 0.4% in a single candle. Exiting all long positions and disabling new longs.')
            self.dp.send_msg(f'BTC dropped more than 1.5%. Exiting all long positions and disabling new longs.')
            self.custom_long_allowed = False
            return True  # Exit long position
        elif btc_pct_change >= 0.4:
            logger.info(f'BTC rose more than 0.4% in a single candle. Exiting all short positions and disabling new shorts.')
            self.dp.send_msg(f'BTC rose more than 1.5%. Exiting all short positions and disabling new shorts.')
            self.custom_short_allowed = False
            return True  # Exit short position
        else:
            self.custom_long_allowed = True
            self.custom_short_allowed = True

        return False

def cod(indicators):
    # change of direction
    diffs = indicators.diff()
    direction_change = np.sign(diffs).diff()
    result = np.where(direction_change > 0, 1, np.where(direction_change < 0, -1, np.nan))

Here’s a tight summary of the critical issues:

Stop-loss math is wrong.
Uses (current_rate - dynamic_sl) / current_rate, which can return ~0.98 (98% loss). Should be dynamic_sl / current_rate and then clip to sane bounds (e.g., 0.5%–10%).

Fake multi-timeframe signals.

Invalid sell_trend_indicator default.

Duplicated Stochastic config/computation.
A duplicated parameter and two STOCH calculations overwrite columns and add noise. Keep a single STOCH block and one parameter set.

Leverage uses absolute ATR.
Thresholds like atr > 1.0/1.5/2.0 don’t scale across coins. Normalize to ATR/close before comparing.

Runtime/setup quirks.
process_only_new_candles=False (slower) and a time.sleep(5) pause on startup; also inconsistent naming (“DarkReaper”). Set to True, remove the sleep, and clean names.
