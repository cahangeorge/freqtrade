Some code review from me and my AI, if I may.

`calculate_market_structure()` func has `shift(-1)` in it which makes it non-backtestable.

In dry/live shift(-1) will return NaN for the last candle becuse no future candle exists yet.

This ` (dataframe['high'] > dataframe['high'].shift(-1))` becomes `false` (because any comparison with a `NaN` is `false`) so everything that depends on these `swing_high` and `swing_low` columns won't work.

Hope this helps in future improvements.
