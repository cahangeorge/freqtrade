@PRO-Members and @BASIC-Members 
The MultiBotDashboard is your command center for running multiple Freqtrade bots like a pro — all in one clean UI. Instead of jumping between terminals, logs and APIs, you get a single place to monitor, compare and manage everything in real time.

✨ What it does

• 🧩 Multi‑Bot Management: See all bots at a glance (status, mode, health)
• ⚡️ Real‑Time Updates: Live refresh via WebSocket — no stale data
• 🔍 Auto‑Discovery: Finds bots automatically (Docker + filesystem scanning)
• 📊 Portfolio Analytics: Aggregated totals (profit, balance, trades, winrate)
• 🏆 Top & Bottom Performers: Instantly see who’s printing and who’s bleeding
• 📜 Trade History: Detailed logs with filtering + export (audit & analysis)
• 🩺 Health Monitoring: Uptime/latency/error awareness so issues don’t hide
• 🚨 Alerts (optional): Drawdown/status change awareness
• 🌙 Dark Mode + 📱 Mobile Ready: Looks great on desktop & phone

🏗️ How it’s built (high level)

• Frontend: React + TypeScript + Tailwind + charts
• Backend: FastAPI (Python) + REST + WebSocket
• Discovery: Docker scan / filesystem scan / API integration
• Auth: JWT + roles (admin/operator/readonly)

🎯 Why it matters

• One dashboard for the entire bot fleet
• Faster decisions, less chaos
• Better transparency: performance, problems, and progress — all visible
