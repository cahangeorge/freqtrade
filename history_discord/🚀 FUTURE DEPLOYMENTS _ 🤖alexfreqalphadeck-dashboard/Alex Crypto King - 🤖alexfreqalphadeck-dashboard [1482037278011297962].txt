🤖 AlexFreqAlphaDeck V1 Released! 🚀
@everyone 
Complete Dockerized trading dashboard for Freqtrade bots!

✨ Features:
📊 Multi-bot management & auto-discovery
📈 Live portfolio analytics & trade history
🔌 Data collector (Bybit, prices, snapshots)
🗄️ Dual PostgreSQL databases (auto-setup)
⚡️ React 18 frontend with WebSocket updates
🔐 JWT auth & role-based access

🚀 Quick Start:

downlad and unpack
cd AlexFreqAlphaDashboard
./install.sh

🌐 Access:

• Dashboard: http://server:5000
• API: http://server:8000/docs
• Adminer: http://server:8090
• Login: admin/admin

🛠️ Stack: Docker, PostgreSQL, Redis, FastAPI, React

📋 Requirements: Docker 20.10+, 4GB RAM, 20GB disk

Made with 🤘 for the Freqtrade community!

Questions? Drop them below! 👇

[03/16/2026 11:16] xf0x0f
I have significantly expanded and hardened the dashboard since the last public revision. The platform now has a real first-time setup flow with a guided wizard, centralized runtime settings, improved mobile usability, multi-language foundations, persistent login behavior, Tailscale support, and much stronger installability for third parties. Core modules like Discovery, Strategy Lab, Finance Data, Pairlist, Alerts, and bot health/metrics were stabilized so the app behaves much more like a product and less like a prototype.
On the infrastructure side, i removed hardcoded IP dependencies from active app paths, centralized API/database/path settings, improved CORS and host handling, added long-lived auth with token refresh, and made the frontend adapt automatically to LAN and Tailscale hosts. Discovery was improved so bots running in host networking can still be detected correctly, API URLs are built reliably, and bot health/metrics/historic snapshots are populated again.


[03/16/2026 11:17] xf0x0f
The Finance section was heavily upgraded. It now includes live Binance and Bybit orderbook views, responsive mobile layouts, clickable news headlines, stock watchlist management with add/remove support, sortable crypto and stock tables, and better settings/help text for external integrations like FRED and News API. Strategy Lab was improved with a visible strategy upload flow, and the setup/settings UI now explains what each important field does and where users obtain required API keys.
The Freqtrade Bots area was reworked from a simple iframe embed into a dashboard-mediated bot UI flow with server-side login preparation, refresh fixes, and safer proxy-based embedding. We also repaired multiple stale frontend/backend integrations, old hardcoded endpoints, schema mismatches, and missing collectors so modules like Strategy Lab, Finance feeds, bot metrics, and historic views produce real data again.
For product polish, we added the first proper i18n layer with German and English switching, improved mobile navigation so the app is usable on phones, and started replacing mixed-language UI text with centralized translations. Across all of this work, repeated smoke tests were run remotely to validate that the main app flows stayed healthy.
