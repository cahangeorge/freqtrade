**🚀 Installation Guide for AlexFreqAI Docker Image 🎓**

Follow these steps to install and run the AlexFreqAI Docker image on your machine. Let’s get started! 🎉
1️⃣ Create a Folder for the Docker Setup 📁

First, make a directory where the Docker setup will be run. You can use the terminal or file explorer to create it.
2️⃣ Clone the Repository 🛠️

Open your terminal and run the following command to clone the repository into the folder you just created:

sudo git clone https://github.com/AlexCryptoKing/freqailstm.git

3️⃣ Navigate to the Project Directory 📂

After cloning the repo, move into the freqailstm directory:

cd freqailstm

4️⃣ Make the Setup Script Executable 🔑

To allow the setup script to run, you need to give it execution permissions:

sudo chmod +x setup_alexfreqailstm.sh

5️⃣ Run the Setup Script 🖥️

Now, you’re ready to run the setup script. This will install everything you need, including the Docker image for AlexFreqAI:

sudo ./setup_alexfreqailstm.sh

6️⃣ Start the Docker Compose 🚢

Once the setup completes, you can start the Docker containers with the following command:

sudo docker compose up

This will launch AlexFreqAI and get your environment up and running! 🎉🚀

And that’s it! 🎉 You’ve successfully installed the AlexFreqAI Docker image. You’re now ready to dive into crypto trading strategies and AI learning models. Good luck! 💰📈

📥** Next Step: Download Necessary Data **📊

Before starting with strategy optimization and backtesting, we need to download the historical data. Follow these steps to proceed!
1️⃣ Download Data 📈

Run the following command to download the necessary data for various timeframes (5m, 15m, 30m, 1h, 2h, 4h, 1d):

freqtrade download-data -c user_data/config-torch.json --timerange 20240101-20240917 --timeframe 5m 15m 30m 1h 2h 4h 1d

This command downloads the data needed for your backtesting and hyperopt processes. 📅

2️⃣ Hyperopt 🔧⚙️

After downloading the data, it’s time to run hyperoptimization to find the best strategy settings. We’ll use the SharpeHyperOptLossDaily loss function.

Run this command to optimize the buy and stoploss spaces:

freqtrade hyperopt --hyperopt-loss SharpeHyperOptLossDaily --spaces buy stoploss -c user_data/config-torch.json --strategy AlexStrategyFinalV9Hyper --timerange=20240616-20240830 -e 1000

    🧠 Strategy: AlexStrategyFinalV9Hyper
    ⏳ Timerange: June 16, 2024 - August 30, 2024
    📊 Epochs: 1000 (to fine-tune the hyperparameters)

3️⃣ Backtest Your Strategy 🧪

Now that we have optimized the strategy, it’s time to test it using a backtest!

Run the following command to backtest the strategy over a specific date range:

freqtrade backtesting --strategy AlexStrategyFinalV9Hyper --config user_data/config-torch.json --cache none --export=signals --timeframe-detail 15m --timerange 20240901-20240925

    No Cache: We avoid using any cached data to ensure accurate results.
    Timeframe: 15m for detailed results.

This will give you a report of how your strategy would have performed! 📈🔬

🎉 Congrats! You've now downloaded data, run hyperoptimization, and performed a backtest of your strategy. Keep refining and testing for the best results! 🚀

📊 V9x Strategy Usage Guide 📊

(V9x - "x" stands for the version number)
This guide explains how to use the V9x strategies (NOT Optuna)

🗂 Files Overview

Depending on the version, you will have 4 files:

    AlexStrategyFinal9x.py
    ➡️ Main strategy file with Progressor/FreqAI enabled.
    👉 To activate FreqAI, set freqai=true in your config file.

    AlexStrategyFinal9x.json
    ➡️ Strategy Parameters File 

    AlexStrategyFinal9xHyper.py
    ➡️ Strategy file for Hyperopt and Backtesting, with Progressor and FreqAI disabled.
    👉 To deactivate FreqAI, set freqai=false in your config file.

    AlexStrategyFinal9xHyper.json
    ➡️ Hyperopt result file.
    This file is generated after running Hyperopt on the AlexStrategyFinal9xHyper.py strategy.

🔄 How to Use the Files

    After Hyperopt is complete, copy the AlexStrategyFinal9xHyper.json file:
    ➡️ AlexStrategyFinal9xHyper.json → AlexStrategyFinal9x.json.

    Update the first line of the AlexStrategyFinal9x.json file to the correct name:
    ➡️ Change it to AlexStrategyFinal9x.json to match the new file name.

🔧 Configuration Tips

    For FreqAI enabled runs: Set freqai=true in the config.
    For Hyperopt or Backtesting: Set freqai=false to disable it.
