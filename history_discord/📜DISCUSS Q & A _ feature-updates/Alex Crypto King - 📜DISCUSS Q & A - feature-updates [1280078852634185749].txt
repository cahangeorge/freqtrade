PROJECT -  HATE v3 (Hierarchical Adaptive Trading Engine)

PROJECT GOAL

The primary goal of this project is to build ai_engine, a state-of-the-art, self-learning, and fully autonomous algorithmic trading system.

This engine is designed as a standalone, plug-and-play Python package intended to operate within the Freqtrade user_data directory. It functions as a sophisticated, decoupled "brain" that any Freqtrade strategy can import and call, reducing the strategy file itself to a simple "loader."

The objective is to create an "unbeatable" system by moving beyond static, single-model strategies and building a multi-layered, adaptive ecosystem that learns from and optimizes its own performance in real-time.

CORE PHILOSOPHY & ARCHITECTURE

The engine is built on three core philosophies:

Hierarchical Specialization: No single AI is responsible for everything. The system is a hierarchy of specialized agents, each handling one part of the problem. This mimics the structure of a quantitative hedge fund:

Layer 1 (Analysts): Generates predictive signals (Alpha).

Layer 2 (Manager): Decides on a strategy based on signals.

Layer 3 (Trader): Executes the strategy with proper risk management.

Layer 4 (Oversight): Provides a qualitative, human-like sanity check.

Continuous Self-Improvement (The Learning Loop): The engine is not static; it is designed to learn. It is built on a foundational "Performance & Learning Loop" (Layer 0) that logs every decision and its outcome, analyzes its own performance, and autonomously triggers the re-optimization of any component that is underperforming.

Decoupled & Modular: The ai_engine is a standalone Python package. The Freqtrade strategy file (my_hate_strategy.py) is a "dumb" client that simply imports and calls the engine's main class. All logic, configuration, and learning are contained within the ai_engine folder.
