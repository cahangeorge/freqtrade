⚡ Quick Installation Overview
🔧 Requirements

Python 3.11+
Git
8GB+ RAM (recommended for local models)

🧠 Install Ollama (Local AI Runtime)
Mac
brew install ollama


Linux
curl -fsSL https://ollama.com/install.sh | sh

Windows
Download from the official site.
Then start Ollama & pull the model:

ollama serve &
ollama pull qwen2.5:7b

📦 Clone & Setup Project
git clone https://github.com/your-repo/nofxfreqtrade.git
cd nofxfreqtrade

python -m venv .venv
source .venv/bin/activate   # mac/linux
.\.venv\Scripts\activate    # windows

pip install -r requirements.txt

Create .env config:

LITELLM_MODEL=ollama/qwen2.5:7b
REASONING_AI_TIMEOUT=30
REASONING_ENTRY_THRESHOLD=55
REASONING_EXIT_THRESHOLD=50
Add your exchange keys to config.json.

🚀 Run the Bot
Dry-run (paper trading):
freqtrade install-ui
freqtrade trade --dry-run

Live trading (⚠️ use caution):
freqtrade trade

👀 Optional — View AI Prompts in Real-Time
python prompt_viewer.py &
freqtrade trade --dry-run
Open in browser:
http://localhost:5555

[01/07/2026 18:29] anonymuis
Some more tips:
1) Do all definitions (regime, trend, volatility) as a named calculation I'm freqtrade. And even give it some older timelines.
2) Not too much, because it gets easily overwhelmed and will forget things. Like it will focus on emas instead of rain and trends or the other way around.
3) ask another agent (not within the same context) to check if the LLM is correct. It will work better because it is  easier to slot errors than to come up with a trading decision.
4) I've even tried with multiple smaller agents each with a specific task and context: one for regime and trending, one for S/R levels, one for choosing a strategy (reversion, breakout, trend following), one as a critic to check on all the others and one for setting up the final exact numbers like multiple entry and exit levels.
5) instead of reinventing a new strategy setup every cycle, stick with one and out it in the prompt withe the question 'is this still viable'
6) Put important instructions and guardrails first. Ask another LLM (like CHATGPT or Claude) to improve the prompt after collecting 10 or so decisions. Again, you will see that it often keeps growing the prompt untill it strat hallucinating again. LESS IS MORE! it keeps the task clear.

You will face some difficulties:
1) It will always try to do what is best, like lowering entries and increasing exits because thats it what the best outcome could be. So it can keep lowering entries every cycle and thus missing the trade.
2) it will very often make up small things that will do crazy stuff like exiting a perfectly good position. Always re-evaluate important decisions (even by another LLM).
3) It's very hard to get all small thing perfectly aligned... Just a minor change in a prompt can make a huge difference in the outcome. Remember: LLMs are text trained and will always find a way to explain things correctly, even if it is not the perfect answer.

Good luck! Let me know if you have some questions.
