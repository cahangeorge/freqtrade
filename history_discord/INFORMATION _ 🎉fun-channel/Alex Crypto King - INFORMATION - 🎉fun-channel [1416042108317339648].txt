Detect a bug in its own codebase

Apply the patch automatically
The orchestrator validates the diff, applies it to the repository, and runs the required test suite. If everything passes, the fix is committed. If not, it rolls back and requests a refined solution.

Self-test the fix before accepting it
The system evaluates the outcome using automated tests and predefined acceptance criteria. Only successful fixes are merged; failed ones are retried automatically.

Run this entire loop without human intervention

Generate full working code from high-level prompts
Beyond self-repair, the system can also create entirely new functionality.
