Here is another aproach i tried to ....
Based on Version9 without changes
I integrated Automated Optuna on it.
This is just a Test i cann not say if it will be profitable.....

It uses the OLD Targets from Version 9 !!

pip install optuna
There are this Files to use for
AlexStrategyFinalV90.py                  - Main Script wor Live/Dry RUN
AlexStrategyFinalV90.json               - json file for Live/Dry RUN
AlexStrategy_Optuna.py                  - Optuna Script
AlexBTStrategyFinalV90.py            - For Backtest!
AlexBTStrategyFinalV90.json         - json file for Backtest   

For Testrun i used this command (for testing)
python ./freqtrade/user_data/strategies/AlexStrategy_Optunan.pyt --showft --trials 10000 --maxtrials 100 --days 30 --download


the main idea is, get first an hyperopted BT json (the attached is a start option but the market already changed). hyperopt recommendation is SharpeHyperOptLossDaily --spaces buy , leave max_open_trades more (30)

it will do around 200 tests per day for a busy machine but you might obtain more
practically after first hyperopt you do not need hyperopt anymore, suggestions from optuna are more scientific than FT hyperopt trials
Example of starting Optuna (in your FT python environment .venv)
python AlexStrategy_Optuna.pyt 
I renamed pyt as the FT has a problem on searching strategies and python scripts in the same folder
