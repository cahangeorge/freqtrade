[08/31/2024 03:56] dodwmd
@AndreiS My workflow involves running Freqtrade in Docker, with the user_data directory mounted to a local volume, and keeping the bot continuously in trading mode. Every few hours or daily, I use Freqtrade to download-data and then launch a separate instance in hyperopt mode. During this process, I use an additional --config argument to modify the freqai.indicator value, ensuring that I remove the existing directory if needed and set a different database location. This allows hyperopt to run and update the JSON without disrupting the active trading bot. Afterward, I restart the trading bot to apply the new hyperopt settings. Additionally, whenever I restart the Docker container, I clear the training models so they are regenerated at startup.
