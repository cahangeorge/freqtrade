[09/29/2024 11:27] anonymuis
You could create a strategy for all three:
First, define (by using indicators) if the current market is bull, bear or range based. You can give these ratings, like 1-10.

Then create your strategy, but use 3 different weights for each indicator: a certain indicator can be very valuable in a range trade, but not when trading up or down.

Then, calculate the results like this:
(Value for current trend bull) * ( (SignalX * (bull weight of signalX)) + (same for signal Y) + (etc)) +
( (value for current trend range) * (SignalX*(range weight of signal Y) etc...

It's a lot of work, but makes it the most flexible in different situations.

Hello all,
I would like to share an approach to hyperoptimize individual trading pairs while using the same strategy. Hyperoptimizing by pair makes sense to me because each crypto has its own specific patterns and behavior. After selecting a large number of pairs, I implemented a script to loop through and hyperoptimize each pair one by one. The results are then concatenated into a single JSON file, which can be directly integrated into the strategy file customized for this purpose.

Advantages:
- Hyperopt is faster (quick convergance)
- No pairs are excluded due to their differences from the rest of the group.
- There's no need to run multiple strategies per hyperopted pair.

Points to Consider:
- Similar to AI, overfitting can occur when using a short time range or certain loss functions.
- The same time period is applied to all pairs.
- May be select only some parameters to be optimized to avoid overfitting

Improvements:
- Automatically selecting the most representative time periods.

For now, I’ve used the following parameters:
--timerange=20240701-20240901 and --hyperopt-loss SharpeHyperOptLossDaily. My initial experiments show that entries are more delayed, as it waits for a better level to be reached. Backtesting the hyperopt period has shown an improved ROI x2.

To make it easy to use, I have a python file to run with arguments
